# Jev

[English](README.md) · **Русский**

Голосовое управление Mac. Приложение постоянно слушает, отправляет услышанную фразу модели
[Jev](https://openrouter.ai/typesafe/jev-1.13) (TypeSafe, через OpenRouter), а та выбирает одну из команд.
Jev не генерирует текст, а только выбирает вариант из списка с вероятностями — поэтому ответ приходит за ~0,5 с.

Команды — это данные, а не код: встроенные лежат в [defaults.json](defaults.json), свои добавляются в
`~/.config/jev/config.json` в том же формате.

## Быстрый старт

Нужны macOS 14+, инструменты командной строки Apple (`xcode-select --install`; полный Xcode не обязателен) и ключ
[OpenRouter](https://openrouter.ai/keys) с небольшим балансом — одно решение Jev стоит около $0.00002.

```bash
git clone https://github.com/mikakostoev/jev-voice-control.git
cd jev-voice-control
cp .env.example .env      # вписать свой OPENROUTER_API_KEY, при желании сменить JEV_LOCALE (ru-RU, en-US, …)
./build.sh                # собирает, подписывает, ставит в ~/Applications/Jev.app и запускает
```

1. **Разрешения.** При первом запуске macOS спросит «Микрофон» и «Распознавание речи» — разрешите. Затем включите Jev в
   *Системные настройки → Конфиденциальность и безопасность → Универсальный доступ* (без этого работают только
   «открой …», поиск и громкость; печать, клавиши и клики — нет). «Запись экрана» понадобится позже, когда вы впервые
   попросите кликнуть в приложении, которое не отдаёт интерфейс через Accessibility (Telegram): Jev сам покажет запрос.
2. **Проверка.** В строке меню появился пункт **Jev**, внизу экрана на пару секунд — капсула «Jev is listening».
   Скажите «открой калькулятор». Потом, с браузером впереди: «открой ютуб», «новая вкладка», «листай вниз», «назад».
3. **Чтобы разрешения не слетали при каждой пересборке** — один раз создайте сертификат подписи: *Связка ключей →
   меню «Связка ключей» → Ассистент сертификации → Создать сертификат…*, имя **`Jev Dev`**, тип удостоверения
   «Самоподписанный корневой», тип сертификата **«Подпись кода»**. `build.sh` подхватит его сам; при первой подписи
   нажмите «Разрешать всегда». Без сертификата приложение подписывается ad-hoc, и после каждой сборки разрешения
   приходится выдавать заново (см. ниже).

Без сети до OpenRouter Jev ничего не делает: распознавание речи локальное, но решение принимает модель.

### Если что-то не работает

| Симптом | Что сделать |
|---|---|
| Непонятно, что происходит | Меню Jev → **Open log** (`~/Library/Logs/Jev.log`): там видно, что расслышано, что решила модель и чем кончилось. |
| После пересборки Jev включён в настройках, но не печатает и не кликает (в логе `accessibility trusted=false`) | Разрешение выдано старой подписи. `tccutil reset Accessibility dev.kostoev.jev-hud`, перезапустить Jev, включить заново. То же для `ScreenCapture`. Лечится сертификатом из шага 3. |
| В логе `cannot listen …` | Не выдан микрофон или распознавание речи, либо язык из `JEV_LOCALE` не поддерживается на этом Mac. |
| В логе `jev request failed: HTTP 5xx / 529` | Сервис модели временно перегружен — бывает сериями по несколько минут; Jev сам повторяет запрос до трёх раз. |
| `HTTP 401/402` | Неверный ключ или кончился баланс OpenRouter. |
| Реагирует на посторонние разговоры | Меню → **Pause listening** (состояние сохраняется между запусками); порог `minConfidence` в конфиге. |

В меню Jev: пауза прослушивания, «Edit commands…», «Open log», выход.

## Свои команды

Меню → **Edit commands…** создаёт и открывает `~/.config/jev/config.json`. Файл перечитывается при сохранении;
при ошибке Jev показывает карточку с местом ошибки и продолжает работать на прежних командах.

```json
{
  "locale": "ru-RU",
  "commands": [
    { "id": "standup",
      "say": "open everything for the daily call: стендап, дейлик, открой всё для созвона",
      "do": [ { "open": "https://meet.google.com" }, { "wait": 1 }, { "open": "Notes" } ] },

    { "id": "next_chat", "app": "Telegram",
      "say": "go to the next chat in the list: следующий чат",
      "do": [ { "keys": "alt+down" } ] },

    { "id": "deploy",
      "say": "deploy the site to production: задеплой проект, выкати на прод",
      "do": [ { "shell": "cd ~/Projects/site && ./deploy.sh" } ] }
  ],
  "disable": ["lock_screen"],
  "sites": { "жира": "mycompany.atlassian.net" },
  "emoji": { "уточка": "🦆" }
}
```

### Поля команды

| Поле | Что значит |
|---|---|
| `id` | Уникальное имя. Совпадает со встроенным `id` — заменяет встроенную команду. |
| `say` | Что читает Jev: описание смысла **плюс примеры фраз**. Точные формулировки не нужны — сопоставление идёт по смыслу. Чем конкретнее описание, тем меньше путаницы с соседними командами. |
| `do` | Шаги по порядку (см. ниже). |
| `app` | Необязательно. Команда предлагается, только когда это приложение впереди (сравнение по части имени). |
| `title` | Необязательно. Заголовок карточки; по умолчанию делается из `id`. |
| `confirm` | Спросить «да/отмена» голосом перед выполнением. По умолчанию `true`, если есть шаг `shell` или `applescript`, иначе `false`. |

### Шаги (`do`)

Каждый шаг — объект ровно с одним ключом.

| Шаг | Пример | Что делает |
|---|---|---|
| `keys` | `{"keys": "cmd+shift+t"}` | Сочетание клавиш в активном приложении. Модификаторы: `cmd`, `shift`, `alt`, `ctrl`, `fn`. Клавиши: буквы, цифры, `enter`, `esc`, `tab`, `space`, `delete`, `up/down/left/right`, `pageup/pagedown`, `home/end`, `f1`–`f12`, знаки `[ ] = - , . / ; ' \``. |
| `open` | `{"open": "https://x.com"}` | Ссылка, путь (`~/Projects`) или имя приложения (`Notes`). Ссылки открываются в браузере по умолчанию. |
| `type` | `{"type": "С уважением, Иван"}` | Печатает текст в поле с фокусом. |
| `click` | `{"click": "Отправить"}` | Клик по элементу на экране; название — как вы бы его произнесли. |
| `shell` | `{"shell": "say done"}` | Команда в `zsh -lc`. Хвост вывода пишется в лог. |
| `applescript` | `{"applescript": "tell application \"Music\" to play"}` | AppleScript. |
| `media` | `{"media": "next"}` | Медиаклавиша: `play`, `next`, `previous`. |
| `wait` | `{"wait": 0.5}` | Пауза в секундах. |
| `builtin` | `{"builtin": "search"}` | Умное действие Jev, которое само разбирает фразу: `open_app`, `open_url`, `open_folder`, `search`, `type_text`, `click`, `emoji`, `set_volume`, `quit_app`, `screenshot`, `repeat`. |

### Остальные ключи файла

| Ключ | По умолчанию | |
|---|---|---|
| `locale` | `JEV_LOCALE` из `.env` | Язык распознавания речи (`ru-RU`, `en-US`, …). |
| `minConfidence` | `0.6` | Ниже этой уверенности Jev молчит (0.3–0.95). |
| `silence` | `0.9` | Сколько секунд тишины считается концом фразы (0.4–3). |
| `disable` | `[]` | `id` встроенных команд, которые надо выключить. |
| `sites` | `{}` | Разговорное название → домен для «открой …». |
| `emoji` | `{}` | Название (или его начало) → эмодзи. |

Незнакомые ключи игнорируются — так в JSON можно держать заметки (`"_readme"`) и выключенные заготовки
(`"_more_examples"`).

## Проверка, что новая команда ничего не сломала

Чем больше команд, тем легче Jev спутать соседние. Оба набора тестов гоняют **настоящую** модель с вашим конфигом:

```bash
J=~/Applications/Jev.app/Contents/MacOS/Jev
$J --selftest                          # разбор фраз, формат конфига, геометрия кликов, один живой запрос
$J --eval Tests/cases.tsv              # фраза → команда (150+ фраз, включая болтовню, которую надо игнорировать)
$J --eval-clicks Tests/clicks.tsv      # экран приложения + фраза → элемент, по которому надо кликнуть
JEV_CONFIG=./my.json $J --eval my.tsv  # попробовать конфиг, не трогая настоящий
```

Формат `cases.tsv`: `фраза<TAB>ожидаемый id[<TAB>предыдущая команда[<TAB>приложение впереди]]`, `a|b` — годится любой,
`none` — Jev должен промолчать. Свою команду стоит проверять минимум тремя строками: две фразы, которые должны
сработать, и одна похожая, которая не должна.

Ответы модели немного плавают от запуска к запуску: единичный промах с уверенностью около порога — шум;
повторяющийся — повод уточнить `say`.

## Как это устроено

| Файл | Роль |
|---|---|
| [Speech.swift](Sources/Jev/Speech.swift) | Непрерывное распознавание речи на устройстве, фраза заканчивается паузой. |
| [Jev.swift](Sources/Jev/Jev.swift) | Клиент `POST /api/alpha/decisions`, разбор фраз (сайты, папки, громкость, текст). |
| [Config.swift](Sources/Jev/Config.swift) | Формат команд, слияние `defaults.json` с пользовательским файлом, проверка ошибок. |
| [App.swift](Sources/Jev/App.swift) | Конвейер: фраза → решение (с учётом того, что видно на экране) → подтверждение → шаги. Режимы `--eval`. |
| [Actions.swift](Sources/Jev/Actions.swift) | Клавиши, печать, клики через Accessibility, запуск приложений, shell. |
| [Screen.swift](Sources/Jev/Screen.swift) | Снимок окна + OCR для приложений, которые не отдают интерфейс через Accessibility. |
| [HUD.swift](Sources/Jev/HUD.swift) | Оверлей: капсула/карточка, шум, кривая вероятностей. |

Клик работает в два этапа. В начале фразы Jev считывает, что видно в активном приложении, — дерево Accessibility
или OCR окна, если приложение почти ничего не отдаёт. Первое решение («какое действие?») видит этот список, поэтому
«перемешай» или «разреши» понимаются как кнопки, а не как болтовня. Второе решение выбирает элемент, сопоставляя по
смыслу и между языками («перешли» → `Forward`).

Лог: `~/Library/Logs/Jev.log` (в него попадает текст всего, что расслышал микрофон).
`kill -USR1 $(pgrep -x Jev)` пишет в `~/Library/Logs/Jev-ui.log`, что Jev видит в активном приложении.

## Известные ограничения

- Кнопки-значки без подписи в приложениях без Accessibility (Telegram) не находятся — OCR видит только текст.
- Порядковые обращения («открой первое видео») не работают: модель получает элементы как неупорядоченный набор.
- Микрофон включён постоянно и слова-активации нет: случайная фраза может совпасть с командой. Опасные шаги
  защищены голосовым подтверждением; остальное — пауза в меню.
- `shell` и `applescript` выполняют произвольный код от вашего имени. Не ставьте им `"confirm": false` без нужды
  и не вставляйте чужие конфиги, не прочитав.
- Эндпоинт решений — недокументированный alpha-API; формат запроса восстановлен по ошибкам валидации и может измениться.
- Проверялось на macOS 26 (Apple Silicon); заявленный минимум — macOS 14.
